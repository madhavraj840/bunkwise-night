Open source

Don't take our word for it. Read the code.

The full source of Night mode for Windows is public on GitHub under the MIT licence. You can check how it dims, confirm that it never connects to the internet, and build it yourself.

Nothing hidden

The app uses no third-party packages and makes no network calls. Your settings are a small JSON file in your own AppData folder.

Same file we published

Each release lists SHA-256 checksums, so you can confirm your download is the file we published.

Safe if it crashes

If the app ever crashes, Windows removes the filter, and the next launch restores your backlight.

Questions

Frequently asked questions

How do I make my laptop screen darker than the lowest brightness?

Install Night mode for Windows. The first part of its scale (0–40) turns the laptop's real backlight down to the hardware minimum. The rest (40–100) uses a full-screen colour filter to keep dimming below that minimum, down to 4% of normal brightness.

Is Night mode free?

The Windows app is completely free and open source under the MIT licence. The Android app is free to download and works as a dimmer without paying. Optional Pro features such as Auto-Dim and schedules are a purchase through Google Play.

Is Night mode open source?

Yes, the Windows app is. Its full C# source is at github.com/madhavraj840/bunkwise-night, and you can build it yourself with the .NET SDK.

Why does Windows say "Windows protected your PC"?

Microsoft Defender SmartScreen shows this box for new apps that aren't code-signed yet. Click More info, then Run anyway. The source code is public, and the SHA-256 checksums on the release page let you confirm the file is the one we published.

What if the screen gets too dark to see?

On Windows, press Ctrl Alt Backspace at any time for full brightness. This works even when you can't see anything. On Android, shake the phone (on by default), press Volume Up and Volume Down together, or tap Off in the notification.

Does Night mode work on Windows 10?

Yes. It runs on 64-bit Windows 10 and Windows 11. It uses .NET Framework 4.8, which is already part of Windows 11 and Windows 10 (May 2019 Update or later), so nothing else has to be installed.

Does it work on a desktop PC or an external monitor?

Yes. Backlight control needs a screen that Windows can dim, which is usually a laptop panel. On other screens, the colour filter does all of the dimming.

Do screenshots come out dark?

Press Ctrl Alt S to take a screenshot at normal brightness. Night mode lifts the filter, opens the Windows snipping tool and dims again afterwards. If you choose the Overlay method in Settings, all screenshots stay at normal brightness.

Does Night mode collect any data?

No. The Windows app works fully offline and makes no network connections. The Android app has no account, no analytics and no ads, and purchases are handled by Google Play.

Is it better than the Windows Night light setting?

They do different jobs. Night light only warms the colours; it doesn't make the screen darker. Night mode lowers the brightness below the laptop's minimum, and its Warm option can add an amber tint at the same time.

Is Night mode an eye-care app?

No. It's a screen dimmer for using your phone or laptop comfortably in the dark. It makes no medical claims and isn't a medical device.
