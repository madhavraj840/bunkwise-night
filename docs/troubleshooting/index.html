Troubleshooting¶

Fixes for the most common problems.

The screen won’t dim¶

  1. Make sure Display over other apps is allowed for Night Mode: Android Settings → Apps → Night Mode → Display over other apps
  2. If you denied the permission once, open Night Mode and tap a level again so it asks for it
  3. Check that Night Mode is switched on and the level is above 0%
  4. On Xiaomi, Redmi and POCO phones, also allow Display pop-up window for Night Mode in the app’s permissions

The screen is too dark to see¶

  1. Shake the phone - this is on by default
  2. Open the notification panel and tap OFF
  3. Switch off the Night mode Quick Settings tile
  4. If you enabled the optional Accessibility service, press Volume Up and Volume Down together

Next time, start from 30% and move up in small steps.

The notification panel isn’t dimmed¶

Dimming the notification panel needs the optional Accessibility service. Tap the “allow Accessibility to dim this panel” prompt in the Night Mode notification and turn the service on. Everything else dims without it.

“Screen overlay detected” when I grant a permission¶

Android blocks permission screens while another app is drawing over the display. Close apps that float over the screen (chat bubbles, other dimmers or colour filters, screen recorders), then open the permission screen again.

Dimming turns off after a while or after a restart¶

  1. Keep the Night Mode notification enabled so Android does not stop it
  2. Turn off battery optimisation for Night Mode: Android Settings → Apps → Night Mode → Battery → Unrestricted (the wording differs by phone)
  3. Aggressive battery management, common on Xiaomi, Oppo, Vivo, Realme and OnePlus phones, can stop background apps. Some of these phones also have an “autostart” permission to enable
  4. After a restart, open Night Mode once and turn dimming on again

The volume-button shortcut doesn’t work¶

The Volume Up + Volume Down shortcut needs the optional Accessibility service. Open Android Settings → Accessibility, find Night Mode, and turn it on. Shaking the phone and the notification OFF button work without it.

My Pro purchase isn’t recognised¶

  1. Make sure you are signed in to Google Play with the same Google account you purchased with
  2. Close and reopen Night Mode
  3. If Pro still does not appear, email us with your order number from Google Play
