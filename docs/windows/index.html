Night mode for Windows¶

Free, open-source screen dimmer for Windows 10 and 11. It makes a laptop screen darker than its own lowest brightness. This is a separate app from the Android app.

Download for Windows (0.4 MB zip) Source on GitHub

What is Night mode for Windows?¶

A free, open-source tray app. It first turns the real backlight down to the hardware minimum, then keeps dimming on screen down to 4% of normal brightness. Windows’ own brightness slider cannot go that low. It needs no account and shows no ads.

How it dims¶

Scale What happens
0–40 The laptop’s real backlight goes down from your current level to the hardware minimum. This also saves battery
40–100 The sub-zero range: a full-screen colour filter dims the screen further, down to 4% of normal brightness. It is never fully black
  • No backlight control: on a desktop or external monitor, the colour filter covers the whole scale instead
  • Overlay method: if the colour filter is not available, or you choose Overlay in Settings, a click-through overlay is used instead
  • Crashes: if the app crashes, Windows removes the filter, and the next launch restores your backlight

Features¶

  • Presets: Evening 30, Reading 50, Dark room 70, Pitch black 90, plus your own
  • Colour: Natural, Warm (amber) or Grey
  • Schedule, with a gradual ease-in
  • App rules: dimming pauses while a chosen app is in front
  • Full brightness for 30 seconds, 1 minute or 5 minutes, after which dimming comes back on its own
  • Remember after restart and Start with Windows (both off by default)

Install¶

  1. Download NightMode-1.1.1-win-x64.zip (0.4 MB) from the official GitHub release
  2. Unzip it: right-click the zip, choose Extract All…, then Extract. You can move the folder anywhere
  3. Run NightMode.exe. If Windows shows “Windows protected your PC”, click More info, then Run anyway. This happens because the app is new and not code-signed yet, and Windows asks only once
  4. Find it in the tray: Night mode lives next to the clock. If you do not see the moon icon, click the ^ arrow, then click the icon to open the panel
  5. Optional: open Settings → Dimming → Start with Windows so it is ready every time you sign in

To uninstall, quit the app from its tray menu and delete the folder. Settings are stored in %APPDATA%\NightMode, which you can delete too.

Verify your download¶

Version 1.1.1, released 11 October 2026. SHA-256 of the zip:

Check it in PowerShell with Get-FileHash .\NightMode-1.1.1-win-x64.zip.

Keyboard shortcuts¶

Keys Action
Ctrl Alt D Turn dimming on or off
Ctrl Alt − / + Darker or brighter, 5% at a time
Ctrl Alt S Take a screenshot at normal brightness
Ctrl Alt Backspace Full brightness right away, even if you cannot see the screen

Requirements¶

  • Windows 10 or 11, 64-bit, with .NET Framework 4.8 (built into Windows 10 May 2019 Update and later; on an older Windows 10 install .NET Framework 4.8 first)
  • Backlight control needs a laptop or another panel Windows can dim. On other screens, the colour filter does all the dimming

Privacy¶

Night mode for Windows works fully offline. It has no account, no ads and no analytics, and it makes no network connections. Settings stay on your PC in a small JSON file.

Windows FAQ¶

Is Night mode for Windows free and open source?¶

Yes. It is free under the MIT licence, and the full C# source is at github.com/madhavraj840/bunkwise-night.

Why does Windows say “Windows protected your PC”?¶

Microsoft Defender SmartScreen shows this for new apps that are not code-signed yet. Click More info, then Run anyway. The source is public and the SHA-256 checksum above lets you confirm the file.

Is it better than the Windows Night light setting?¶

They do different jobs. Night light only warms colours. Night mode lowers brightness below the laptop minimum, and its Warm option can add an amber tint at the same time.

Do screenshots come out dark?¶

Press Ctrl Alt S for a screenshot at normal brightness. Night mode lifts the filter, opens the Windows snipping tool and dims again afterwards.

Build from source¶

You need the .NET SDK and the .NET Framework 4.8 Developer Pack. The app has no NuGet packages.

git clone https://github.com/madhavraj840/bunkwise-night
cd bunkwise-night
dotnet run --project checks
dotnet build NightMode.csproj -c Release -p:DebugType=none
